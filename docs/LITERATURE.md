# Literature

Every source the project has read or relies on, with what we took from it and what we
concluded. Kept up to date in every step (see CONTRIBUTING.md). Rules:

- A source gets a row when it is first read for a step, whether it is used or not.
  A row is never deleted. A superseded or rejected source keeps its row with the
  reason.
- **Took** gives only numbers and statements the source itself reports (with table or
  figure where known). **Concluded** gives our interpretation, assumptions and
  roundings, marked as such.
- **Read** says how much we read: full text, abstract, supplement (data tables), or
  cited second-hand (through another source, not read).
- **Used in** gives the roadmap step and the code that carries the values. The code
  docstring repeats the reference.

Status: **used** (values in the code), **context** (informs a definition or a
decision, no values), **considered** (read, not used, reason given), **superseded**.
